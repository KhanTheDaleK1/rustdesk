# Gemini Project: RustDesk

This document provides a guide for interacting with the `RustDesk` project using Gemini.

## Project Overview

RustDesk is a remote desktop solution written in Rust. It works out of the box with no configuration required and gives you full control of your data.

## How to Use

To get started, you can ask Gemini to perform the following tasks:

*   **List files:** "List the files in the `7_rustdesk` directory."
*   **Read a file:** "Read the contents of the `Cargo.toml` file."
*   **Summarize the project:** "Summarize the RustDesk project."
*   **Explain how to build the project:** "How do I build RustDesk on Linux?"
*   **What is the file structure?**: "Describe the file structure of the RustDesk project."

*This document is intended for use with the Gemini CLI.*
